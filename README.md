# Tarou 下载

本仓库仅存放安装包的发布信息，应用源码位于 [tarou](https://github.com/Waaatanuki/tarou)。

- [Chrome 扩展下载](https://github.com/Waaatanuki/tarou-downloads/releases?q=extension-v&expanded=true)
